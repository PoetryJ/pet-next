1. DeepSeek SuperAgent（本项目已vendored，先读本地upstream/PROVENANCE.json确定固定版本）

2. Anthropic The components of agent memory
https://www.anthropic.com/research/components-of-agent-memory
借日志、笔记、知识表示、上下文注入与后台整理的分工。当前选任务条件作为记忆表示，不再建通用记忆数据库；引用原话不等于编译语义正确，必须有独立对照。

3. Common Expression Language
https://cel.dev/overview/cel-overview
成熟的compile-once/evaluate-many、宿主声明变量和受限表达式思想。R6只用小型有限JSON条件，不引入另一门运行环境/完整语言；提供的三值内核是经典逻辑参考实现，不是研究创新声明。

4. Temporal TypeScript message passing
https://docs.temporal.io/develop/typescript/workflows/message-passing
借Signal、condition、持久timer模式；本地桌宠继续用已有scheduler/SQLite，暂不部署Temporal服务。

5. Horvitz 1999 Principles of Mixed-Initiative User Interfaces
https://www.microsoft.com/en-us/research/wp-content/uploads/2016/11/chi99horvitz.pdf
“何时介入”对应经典主动性/不确定性/注意力成本问题。先测漏办与打扰，不直接堆一个无法校准的加权奖励函数。

6. dsh-pet生态
https://github.com/PC2005-cloud/dsh-pet （API.md/openapi.yaml/src/client/todo-bubble.ts）
