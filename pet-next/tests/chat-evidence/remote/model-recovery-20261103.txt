三、可执行恢复命令（由负责人二选一执行，执行方不代跑）
------------------------------------------------
方案 A（恢复原模型 qwen3.8-27b）：
  前置：qwen3.8-27b 权重路径需负责人提供（本机未找到）；siren3 需补装 vllm（见缺项）。
  /opt/conda/envs/siren3/bin/python -m vllm.entrypoints.openai.api_server \
    --model <负责人提供的 qwen3.8-27b 权重目录> \
    --served-model-name qwen3.8-27b \
    --host 127.0.0.1 --port 18872 --max-model-len 8192
  健康检查（服务器本机）：curl -s http://127.0.0.1:18872/v1/models | grep qwen3.8-27b
方案 B（用本机现存 DeepSeek-R1-Distill-Qwen-14B 替代，需产品配置同步改）：
  /opt/conda/envs/siren3/bin/python -m vllm.entrypoints.openai.api_server \
    --model /data3/DATA/models/DeepSeek-R1-Distill-Qwen-14B \
    --served-model-name deepseek-r1-distill-qwen-14b \
    --host 127.0.0.1 --port 18872 --max-model-len 8192
  注意：这是推理蒸馏模型（生成含 <think> 链），与产品"一两句简短中文"提示词不匹配，
  需要负责人物理验收回复质量；且产品侧模型名要改（chat-remote 探测/配置的 model 字段），
  属产品决策，不在本轮执行。
