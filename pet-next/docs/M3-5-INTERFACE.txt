二、试用入口接口（B 实现依据，D 验收依据）
------------------------------------------------
命令：pnpm chat:trial [--context=on|off]
  - 缺省 off；on|off 之外任何值（含 --context 不带值、未知 flag）→ 非零退出（exit 2）
  - on  → 子进程 env 设 PET_NEXT_CHAT_CONTEXT='1'
  - off → 从子进程 env 删除 PET_NEXT_CHAT_CONTEXT（父 shell 继承值必须清除）
  - 启动第一行日志：[chat-trial] 上下文=on（连续对话，4 轮/2000 字符上界）
                     或 [chat-trial] 上下文=off（单轮，与 M3-1 行为一致）
实现约束：
  - chat-trial.mjs 解析参数并改 env 后**复用 chat-remote.mjs 全链**
    （动态 import；配置/隧道/健康探测/退出链不重实现）
  - 不自动发送消息、不暗中 fallback fake、不硬编码地址/凭据
  - 产品消费点已存在：electron/main.ts 按 PET_NEXT_CHAT_CONTEXT 非空启用有界历史
  - pnpm 参数透传由接线保证：参数追加到 script 命令末尾（B 的模块测试直接测
    process.argv 解析，不依赖 pnpm 行为）
package.json 接线（负责人已完成）：
  "chat:trial": "pnpm build && node scripts/chat-trial.mjs"
